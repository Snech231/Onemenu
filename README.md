## 🌐 OneMenu — Удобный серверный DNS

**OneMenu** — это легковесный и быстрый инструмент для управления серверным DNS. Забудьте о сложных конфигурациях и командной строке: теперь управление маршрутизацией, доменами и подключениями доступно через интуитивно понятный интерфейс.

### ✨ Главные особенности:
*   **Простота настройки:** Управляйте DNS-записями и маршрутами без необходимости писать сложные конфиги вручную.
*   **Высокая скорость:** Благодаря оптимизированному ядру, OneMenu обеспечивает минимальные задержки при обработке запросов.
*   **Мультиплатформенность:** Работает на Windows, Linux и macOS.
*   **Гибкость:** Поддержка кастомных правил маршрутизации, перенаправления доменов и работы с локальными серверами.
*   **Автономность:** Полностью работает в фоне, не нагружая систему. Легко интегрируется с существующей серверной инфраструктурой.
*   **Чистый интерфейс:** Современный дизайн, темная/светлая тема, всё для комфортной работы.

### ⚙️ Системные требования:
*   **ОС:** Windows 10 / 11 (64-bit), Linux, macOS.
*   **Права:** Требуются права администратора для прослушивания сетевых портов.
*   **Сеть:** Стабильное интернет-соединение.

> 💡 **Установка не требуется:** Просто скачайте `OneMenu.exe`, запустите, и сервер начнет работу. Все настройки сохраняются в локальный конфигурационный файл.

## 🇬🇧 English (Short Description)

**OneMenu** is a lightweight and fast server DNS management tool. It provides an intuitive interface for managing DNS records, routing rules, and local server connections without the need to edit complex configuration files. Fully optimized for performance and available on Windows, Linux, and macOS. No installation required — just run `OneMenu.exe`.
